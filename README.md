# Krish Portfolio

A clean, modern personal portfolio website built with HTML, CSS, and JavaScript. This project showcases a developer profile, key skills, featured projects, social links, and contact information in a responsive and visually appealing single-page layout.

## Live Demo

https://krishkr-ctl.github.io/krish/

## Overview

This portfolio site is designed to present the creator as a web developer with a polished personal brand. It includes:

- A professional hero section with a profile image
- Animated typography and motion effects
- Responsive layout for mobile and desktop
- Skills and service highlights
- Featured project cards with live links
- Social media and contact section

## Tech Stack

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## Run Locally

1. Clone the repository:

```bash
git clone https://github.com/krishkr-ctl/krish.git
```

2. Navigate to the project folder:

```bash
cd krish
```

3. Open `index.html` in your browser.

You can also use a local web server if you want a smoother experience:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

## Customization

You can easily personalize this portfolio by updating:

- Name and title in `index.html`
- Profile image asset (`dp_enhanced_full-1.jpg.jpeg`)
- Skills and project descriptions
- Social media and contact links
- Colors and styling in the CSS section
